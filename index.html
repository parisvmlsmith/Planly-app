About this prototype

Planly 2.0 is a free, offline rule-based plan detection experiment. It is not connected to a language model, WhatsApp or your iPhone calendar.

It works best with separate chat lines and explicit wording. It can misunderstand dates, agreements and changes. Always review details before saving.

For privacy, test with fictional conversations or messages you have permission to use. GitHub Pages serves the public app code, but this prototype doesn't send pasted text to a server.
